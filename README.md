# DMZ Lab - Configuración de Zona Desmilitarizada

Este repositorio contiene el desarrollo de un laboratorio de redes en Cisco Packet Tracer, enfocado en la implementación y seguridad de una **DMZ (Demilitarized Zone)** para proteger servicios públicos de una red interna corporativa.

## 目的 (Objetivo del Proyecto)
El propósito de este laboratorio es diseñar y configurar una infraestructura de red que permita separar los servicios accesibles desde Internet (como servidores Web) de los recursos internos de la organización, utilizando políticas de filtrado de tráfico para mitigar riesgos de seguridad.

## Contenido del Repositorio
* `/dmz-lab.pkt`: Archivo final del laboratorio en Cisco Packet Tracer.
* `/informe/Informe_DMZ_Laboratorio.md`: Documentación técnica detallada siguiendo la plantilla oficial.
* `/evidencias/`: Capturas de pantalla que validan la conectividad y las reglas de firewall.

## Tecnologías Utilizadas
* Cisco Packet Tracer
* Protocolos de Enrutamiento
* Listas de Control de Acceso (ACLs)
* Servicios: HTTP/HTTPS, DNS y Email.
